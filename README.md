# Прогноз погоды и отчёт по дням

Напишите программу `main.py`, которая получает почасовой прогноз для Берлина, сохраняет его в `weather.csv`, а статистику температуры по каждому дню — в `daily_temperatures.json`.

Получите данные с `https://api.open-meteo.com/v1/forecast` с такими параметрами:

```text
latitude=52.52
longitude=13.41
hourly=temperature_2m,relative_humidity_2m,weather_code,wind_speed_10m
wind_speed_unit=ms
```

Описание ответа есть в [документации Open-Meteo](https://open-meteo.com/en/docs). В разделе `hourly` находятся время и показатели для каждого часа. Температура указана в °C, влажность — в %, скорость ветра — в м/с. Сохраняйте даты и время из ответа без перевода в другой часовой пояс: при этих параметрах API использует GMT/UTC. Обработайте все полученные часы; даты и количество записей заранее неизвестны.

В `weather.csv` должны быть заголовки именно в таком порядке:

```csv
date,time,temperature_2m,relative_humidity_2m,wind_speed_10m,weather_description
```

Для каждого часа создайте отдельную строку. Дата имеет вид `2026-10-22`, время — `09:00`. Сохраните порядок часов из ответа и исходные значения показателей. Вместо кода погоды запишите английское описание из [weather_codes.json](weather_codes.json). Для неизвестного кода используйте `Unknown (123)`, где `123` — полученный код. Если показатель или код равен `null`, оставьте соответствующую ячейку CSV пустой. Нулевая температура или скорость ветра — это значение, а не пропуск.

В `daily_temperatures.json` сохраните по одной записи на каждую дату в порядке возрастания. У записи четыре поля: `date`, `average_temperature`, `min_temperature`, `max_temperature`. Рассчитайте показатели по полученным почасовым температурам этой даты, включая неполные дни. Среднюю температуру округлите до двух знаков после точки; минимум и максимум сохраните без дополнительного округления. Если среднее находится ровно посередине между двумя вариантами округления, допустим любой из них. Пропущенные температуры не участвуют в расчёте. Если за день нет ни одной известной температуры, все три показателя этого дня равны `null`.

Например, для выдуманных часов:

```json
{
  "hourly": {
    "time": ["2026-10-22T23:00", "2026-10-23T00:00", "2026-10-23T01:00"],
    "temperature_2m": [10, 0, 4],
    "relative_humidity_2m": [80, 90, 85],
    "weather_code": [0, 3, 61],
    "wind_speed_10m": [2.5, 0, 1.2]
  }
}
```

получится `weather.csv`:

```csv
date,time,temperature_2m,relative_humidity_2m,wind_speed_10m,weather_description
2026-10-22,23:00,10,80,2.5,Clear sky
2026-10-23,00:00,0,90,0,Overcast
2026-10-23,01:00,4,85,1.2,Slight rain
```

и `daily_temperatures.json`:

```json
[
  {"date": "2026-10-22", "average_temperature": 10, "min_temperature": 10, "max_temperature": 10},
  {"date": "2026-10-23", "average_temperature": 2, "min_temperature": 0, "max_temperature": 4}
]
```

Если используете сторонние пакеты, перечислите их в `requirements.txt`.

CSV и JSON сохраняйте в UTF-8, CSV — с запятой в качестве разделителя и точкой в дробных значениях.

Ввод с клавиатуры не нужен. После записи выведите английское сообщение с именами обоих файлов, например:

```text
Saved weather.csv and daily_temperatures.json
```
